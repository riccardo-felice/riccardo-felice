# Riccardo Felice

Master's Degree in Bioengineering, University of Padova. Biomedical signal processing and wearable data.

## Projects

| Project | Description |
|---|---|
| [Thesis: EDA synchrony with compressive sampling](thesis-eda-sparse-synchrony/) | Sparse representation (Bateman dictionary + Orthogonal Matching Pursuit) of electrodermal activity to detect patient–therapist synchrony. MSc thesis (in Italian). |
| [ECG denoising](ecg-denoising/) | Butterworth low-pass filter vs. FFT thresholding on a synthetic ECG at 0 dB SNR. MATLAB + report. |
| [PPG peak detection](ppg-peak-detection/) | AMPD, MSPTD and qppgfast compared on the TROIKA dataset during exercise. MATLAB + report. |
| [Glucose trend and daily cycle](glucose-trend-decomposition/) | Separation of monthly trend and daily cycle in self-monitored glucose data. MATLAB + report (in Italian). |
| [CGM artifact detection](cgm-artifact-detection/) | Detection of compression artifacts in CGM traces with an AR model and recursive least squares. MATLAB + report (in Italian). |
| [EDA Stress App](eda-stress-app/) | Team project: mobile app estimating physical and mental stress from heart rate, EDA and sleep. Presentation only, source code not public. |
